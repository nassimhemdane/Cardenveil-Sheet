Fiche Cardenveil - Version Windows

Contenu :
- FicheCardenveil.exe
- ressources internes de l'application

Utilisation :
1. Décompressez entièrement le dossier.
2. Lancez FicheCardenveil.exe.
3. Votre navigateur s'ouvrira automatiquement sur la fiche.

Sauvegardes locales :
Les personnages, images et données utilisateur sont stockés ici :
%LOCALAPPDATA%\FicheCardenveil\

Vous pouvez partager une fiche complète avec :
- Exporter ZIP

Et la réimporter avec :
- Importer fiche

Notes :
- Ne lancez pas l'application directement depuis l'archive zip.
- Gardez le dossier complet tel quel après décompression.
